# Agent-Portabilität und Claude Code

Primärplattform: **Claude Code**. Entry Point `SKILL.md`, Referenzen und lokale Python-Validatoren sind portables Text-/Dateimaterial. Die `agents/openai.yaml` ist ein zusätzlicher Adapter für andere Umgebungen; Claude Code benötigt sie nicht.

Nicht garantiert: identisches Triggering, tool availability, Shell, UI install, Browser-Automation, API-Schreibrechte, Tracking, Laufzeitumgebung, Modellverhalten. Keine Aussagen über ungetestete Frontier-Runtimes. Dies ist ein **Claude-first**-Skill, nicht ein allgemeiner autonomer Web-Agent. Security- und Evidenzgrenzen bleiben modellagnostisch.
